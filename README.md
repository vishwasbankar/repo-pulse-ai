# RepoPulse AI

AI-Powered GitHub Repository Health Analyzer & Hackathon Judge.

## Project Overview

RepoPulse AI analyzes GitHub repositories and evaluates:

- Maintainability
- Security
- Documentation
- Testing
- Technical Debt
- Git History
- Future Repository Health
- AI Project Summary
- Requirement Matching
- Evidence-Based Hackathon Judging
- Technology Recommendations
